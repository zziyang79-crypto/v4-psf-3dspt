# Reference data

Only small reference data are included in this repository.

- `psf_templates_20x/10015.tif`–`10035.tif`: measured 20× PSF templates (1 µm z step).
- `psf_templates_20x_roicheck/original-10015.tif`–`original-10035.tif`: independent-check templates used by the QC stress benchmark.
- `example_roi/20x_ROI2_2-1.tif`: one small 20× fluorescence ROI used as a decoder example.

Full raw fluorescence/scattering stacks are not included; see the manuscript's Data Availability statement.
